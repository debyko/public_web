02What the service is #

DEBYKO collects market data from the public interfaces of crypto trading venues and shows it with its source, receive time, age and gaps kept visible. It is offered as:

  • Studio — a web interface: live comparison of venues, history and point-in-time replay of what each venue showed.
  • API — the same data for your code, under the same key.
  • Agent — conditions you write in DQL, evaluated on your schedule; when one becomes true, Agent notifies you by Telegram or webhook with the values it fired on. Agent sends notifications, never instructions.
  • Runner — software you run on your own infrastructure. It receives a webhook from Agent or Studio and places orders on an exchange with your own API keys. We publish it; we do not run it and never receive your keys.
  • Arena — a public board of agents, built from execution reports that Runners send back. Every figure on it says whether it is self-reported or verified.

Which of these is available, in preview or planned is stated in the pricing section of the home page. Nothing on this site is available beyond what is stated there.
